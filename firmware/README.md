# Прошивка RP2040-Zero

PlatformIO-проект для Waveshare RP2040-Zero на Arduino-Pico.

Прошивка LayoutBeep 2.8 использует протокол `LB6` и поддерживает до шести универсальных профилей раскладок. Названия языков и Windows Layout ID на плату не передаются: RP2040 получает только индекс профиля, цвет и параметры звукового сигнала.

## Подключение

- встроенный WS2812B: GPIO16;
- пассивный пьезоизлучатель: GPIO15 → 100–220 Ом → пьезо → GND.

## Сборка

```bash
pio run
```

UF2 обычно находится здесь:

```text
.pio/build/waveshare_rp2040_zero/firmware.uf2
```

## Профили

Windows отправляет для каждой раскладки:

```text
P,index,hz,ms,r,g,b
```

Текущая раскладка задаётся командой:

```text
L,index,switched
```

Подробности протокола находятся в корневом `PROTOCOL.md`.

## Ночной профиль

Windows-программа отправляет:

```text
N,active,dayVolumePct,nightVolumePct,nightBrightnessPct
```

Дневная и ночная громкость независимы. Ночная яркость применяется к постоянному цвету текущей раскладки и вспышке переключения. Оранжевый offline-индикатор остаётся фиксированной яркости.

Прошивка LB6 сохраняет совместимость с основными командами LB5 для первых двух профилей.
