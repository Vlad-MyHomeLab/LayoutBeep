# USB-протокол LayoutBeep ↔ RP2040-Zero

Обмен идёт через USB CDC строковыми командами, заканчивающимися переводом строки.

Версия протокола для LayoutBeep 2.8 — `LB6`.

## Проверка платы

ПК отправляет:

```text
?
```

Плата отвечает:

```text
LB6 RP2040-ZERO 2.8
```

## Общая вспышка

```text
G,flashMs,flashR,flashG,flashB
```

Пример:

```text
G,80,90,90,90
```

## Профили раскладок

Windows назначает установленным раскладкам индексы `0..5` и передаёт параметры каждого профиля:

```text
P,index,hz,ms,r,g,b
```

Пример:

```text
P,0,1450,75,0,0,28
P,1,850,75,28,0,0
P,2,1150,75,0,28,0
```

RP2040 не знает названия языков и системные идентификаторы раскладок. Она хранит только индекс профиля и его параметры.

## Текущая раскладка

```text
L,index,switched
```

Примеры:

```text
L,0,0
L,2,1
```

- `switched=0` — тихая синхронизация текущего профиля без сигнала и вспышки;
- `switched=1` — подтверждённое переключение: установить профиль, сделать вспышку и воспроизвести его звук.

## Тест профиля

```text
T,index
```

Команда воспроизводит звук и вспышку указанного профиля, но не меняет постоянный цвет текущей раскладки.

## День / ночь

```text
N,active,dayVolumePct,nightVolumePct,nightBrightnessPct
```

Пример:

```text
N,1,70,20,15
```

Означает:

- сейчас активен ночной профиль;
- дневная громкость — 70%;
- ночная громкость — 20%;
- ночная яркость текущего профиля и вспышки — 15%.

Оранжевый offline-индикатор не масштабируется ночной яркостью.

## Heartbeat

```text
K
```

Используется для контроля связи с Windows-программой.

## Совместимость с LB5

Прошивка LB6 продолжает понимать команды прежнего протокола:

```text
C,...
E0 / E1
R0 / R1
TE / TR
```

Они отображаются на профили `0` и `1`. Windows-программа 2.8 также умеет подключаться к прошивке LB5, но старая прошивка физически поддерживает только первые два профиля. Для полноценной работы 3–6 раскладок требуется прошивка LB6.
