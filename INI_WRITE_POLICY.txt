ПОЛИТИКА РАБОТЫ С LayoutBeep.ini
================================

1. Если LayoutBeep.ini отсутствует, программа МОЖЕТ и ДОЛЖНА создать новый файл
   с полным набором текущих настроек по умолчанию.

2. Если LayoutBeep.ini уже существует, программа НИКОГДА не должна:
   - пересоздавать файл;
   - обнулять или truncate-файл;
   - заменять файл новым;
   - переписывать весь файл целиком;
   - нормализовать его форматирование;
   - удалять неизвестные секции, ключи или комментарии.

3. При явном изменении настройки программа изменяет только значение конкретного
   ключа, который действительно изменился.

4. Неизвестные секции/ключи, комментарии, пустые строки, порядок строк и прочее
   содержимое должны сохраняться максимально точно.

5. Автоматические runtime-события (переключение раскладки, heartbeat, USB reconnect,
   day/night-переход, блокировка/разблокировка) не должны изменять существующий INI.
