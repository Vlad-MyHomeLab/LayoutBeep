# LayoutBeep + RP2040-Zero

LayoutBeep — небольшая нативная программа для Windows 10/11, которая отслеживает **фактическое изменение раскладки** системного индикатора Windows и передаёт состояние по USB на плату Waveshare RP2040-Zero.

Плата показывает текущую раскладку цветом встроенного WS2812B, при переключении делает короткую вспышку и воспроизводит звуковой сигнал через пассивный пьезоизлучатель.

## Возможности

- отслеживание реального состояния `ENG / РУС`, а не только нажатия горячих клавиш;
- USB CDC-связь с RP2040-Zero;
- отдельные цвета, частоты и длительности сигналов для English и Русский;
- настраиваемая вспышка при переключении;
- отдельная дневная громкость;
- ночной режим по расписанию с отдельной громкостью и яркостью;
- оранжевый offline-индикатор на RP2040 не приглушается ночным режимом;
- автоматическое переподключение платы;
- настройки хранятся в `LayoutBeep.ini` рядом с EXE;
- если INI отсутствует, программа создаёт его с полным набором настроек по умолчанию;
- существующий INI **никогда не пересоздаётся и не перезаписывается целиком**: при сохранении меняются только конкретные значения изменённых ключей;
- нативный Win32 x64: без .NET, без CRT и без установщика.

## Аппаратная часть

Waveshare RP2040-Zero:

- встроенный WS2812B — GPIO16;
- пассивный пьезоизлучатель — GPIO15 через резистор примерно 100–220 Ом на GND.

## Структура проекта

```text
windows/        Windows-приложение
firmware/       PlatformIO-прошивка RP2040-Zero
PROTOCOL.md     USB-протокол между ПК и платой
```

## Сборка Windows-программы

Локально из **x64 Native Tools Command Prompt for VS 2022**:

```bat
cd windows
build_msvc.bat
```

Результат:

```text
windows/LayoutBeep.exe
```

## Сборка прошивки

Нужен PlatformIO:

```bash
pio run -d firmware
```

UF2:

```text
firmware/.pio/build/waveshare_rp2040_zero/firmware.uf2
```

## Настройки и правило INI

`LayoutBeep.ini` является пользовательским файлом и **не хранится в Git**. В репозитории есть только пример `windows/LayoutBeep.example.ini`.

Правило проекта:

- отсутствующий INI можно создать целиком;
- существующий INI нельзя заменять, пересоздавать, обнулять или нормализовать;
- при изменении настройки разрешено менять только значение соответствующего ключа, сохраняя комментарии, неизвестные секции, порядок строк и остальные данные.
