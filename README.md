# LayoutBeep + RP2040-Zero

LayoutBeep — небольшая нативная программа для Windows 10/11, которая отслеживает фактическую раскладку активного окна и передаёт её состояние по USB на Waveshare RP2040-Zero.

Плата показывает текущую раскладку цветом встроенного WS2812B, при переключении делает короткую вспышку и воспроизводит звуковой сигнал через пассивный пьезоизлучатель.

## Возможности

- список профилей автоматически берётся из раскладок, установленных в Windows;
- поддерживается до 6 раскладок одновременно;
- у каждой раскладки свои цвет LED, частота и длительность звукового сигнала;
- текущая раскладка определяется по HKL активного окна и подтверждается двумя последовательными чтениями;
- системный Input Indicator дополнительно читается для диагностики;
- USB CDC-связь с RP2040-Zero;
- настраиваемая вспышка при переключении;
- отдельная дневная громкость;
- ночной режим по расписанию с отдельной громкостью и яркостью;
- оранжевый offline-индикатор на RP2040 не приглушается ночным режимом;
- автоматическое переподключение платы;
- для текущей раскладки можно назначить WAV как резервный звук на ПК;
- настройки хранятся в `LayoutBeep.ini` рядом с EXE;
- если INI отсутствует, программа создаёт его с общими настройками и профилями фактически установленных раскладок Windows;
- существующий INI не пересоздаётся и не перезаписывается целиком: при сохранении меняются только необходимые ключи;
- нативный Win32 x64: без .NET, без CRT и без установщика.

Если в Windows установлено больше шести раскладок, LayoutBeep использует первые шесть, возвращённые системой.

## Профили раскладок

LayoutBeep не предполагает наличие English, Русского или какого-либо другого языка. При первом запуске список получается через Windows `GetKeyboardLayoutList()`.

Для каждой найденной раскладки создаётся отдельный профиль. Например:

```ini
[Layout_00000409]
Hz=1450
Ms=75
R=0
G=0
B=28
Wav=
```

Имя раскладки для интерфейса читается из системного реестра Windows. Идентификатор секции соответствует идентификатору конкретной раскладки Windows, поэтому несколько раскладок одного языка могут иметь независимые настройки.

При обновлении с 2.7.x старые параметры English/Russian используются как начальные значения для соответствующих системных раскладок, если для них ещё нет новых секций. Существующий INI при этом автоматически не мигрируется целиком.

## Аппаратная часть

Waveshare RP2040-Zero:

- встроенный WS2812B — GPIO16;
- пассивный пьезоизлучатель — GPIO15 через резистор примерно 100–220 Ом на GND.

## Структура проекта

```text
windows/        Windows-приложение
firmware/       PlatformIO-прошивка RP2040-Zero
PROTOCOL.md     USB-протокол между ПК и платой
```

## Сборка Windows-программы

Локально из **x64 Native Tools Command Prompt for VS 2022**:

```bat
cd windows
build_msvc.bat
```

Результат:

```text
windows/LayoutBeep.exe
```

## Сборка прошивки

Нужен PlatformIO:

```bash
pio run -d firmware
```

UF2:

```text
firmware/.pio/build/waveshare_rp2040_zero/firmware.uf2
```

## Настройки и правило INI

`LayoutBeep.ini` является пользовательским файлом и не хранится в Git. В репозитории есть только пример `windows/LayoutBeep.example.ini`.

Правило проекта:

- если INI отсутствует, программа создаёт его полностью;
- существующий INI нельзя заменять, пересоздавать, обнулять или нормализовать;
- при изменении настройки меняется только соответствующий ключ, остальные строки, комментарии, неизвестные секции и порядок данных сохраняются.
