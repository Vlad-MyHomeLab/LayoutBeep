# Проверки проекта

Перед публикацией выполнено:

- `windows/LayoutBeep.c` компилируется `clang-cl` с `/W3 /WX` до object-файла;
- пользовательский `LayoutBeep.ini` не входит в репозиторий;
- собранные `.exe` не входят в репозиторий;
- `WritePrivateProfileStringW` не используется;
- существующий INI изменяется точечно, только по изменённым ключам;
- при отсутствии INI создаётся полный файл с настройками по умолчанию;
- автоматический переход день/ночь не пишет INI;
- оранжевый offline-индикатор не масштабируется ночной яркостью;
- выполнен поиск типичных секретов, email-адресов, приватных IP и локальных абсолютных путей — совпадений в публикуемых файлах нет.

Полная сборка `LayoutBeep.exe` и `firmware.uf2` выполняется GitHub Actions.
