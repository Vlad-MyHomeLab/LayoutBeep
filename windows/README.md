# Windows-приложение LayoutBeep

Нативное Win32 x64 приложение без .NET, CRT и установщика.

## Сборка

Откройте **x64 Native Tools Command Prompt for VS 2022**:

```bat
build_msvc.bat
```

## Раскладки

При запуске LayoutBeep получает список установленных раскладок через `GetKeyboardLayoutList()` и создаёт до шести профилей. Никакие языки не зашиты как обязательные.

Текущая раскладка определяется по HKL активного окна. Изменение принимается после двух одинаковых последовательных чтений.

Каждый профиль имеет собственные:

- частоту сигнала;
- длительность сигнала;
- цвет WS2812;
- необязательный WAV для резервного звука на ПК.

## Конфигурация

Пользовательский файл `LayoutBeep.ini` создаётся рядом с `LayoutBeep.exe` при первом запуске, если файла ещё нет. В него записываются общие настройки и профили раскладок, фактически найденных в Windows.

Если файл уже существует, приложение не перезаписывает его целиком: изменяются только конкретные ключи, которые действительно требуется сохранить.

`LayoutBeep.ini` исключён из Git. Для примера используйте `LayoutBeep.example.ini`.
