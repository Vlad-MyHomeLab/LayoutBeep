# Windows-приложение LayoutBeep

Нативное Win32 x64 приложение без .NET, CRT и установщика.

## Сборка

Откройте **x64 Native Tools Command Prompt for VS 2022**:

```bat
build_msvc.bat
```

## Конфигурация

Пользовательский файл `LayoutBeep.ini` создаётся рядом с `LayoutBeep.exe` при первом запуске, если файла ещё нет.

Если файл уже существует, приложение не перезаписывает его целиком: изменяются только значения конкретных настроек, которые изменил пользователь.

`LayoutBeep.ini` исключён из Git. Для примера используйте `LayoutBeep.example.ini`.
