# Правила разработки

## Язык

- сообщения коммитов — на русском языке;
- описания изменений, issues и pull request по возможности — на русском языке;
- имена API, библиотек, функций и протокольных команд остаются в исходном техническом виде.

## Конфиденциальность

Перед каждым коммитом необходимо проверить, что в него не попали:

- пользовательский `LayoutBeep.ini`;
- API-ключи, токены, пароли, приватные ключи;
- email-адреса и персональные данные;
- приватные IP-адреса и локальные абсолютные пути;
- собранные EXE и временные файлы.

Для автоматической проверки используется:

```bash
python scripts/check_public.py
```

## LayoutBeep.ini

Существующий INI запрещено перезаписывать или пересоздавать целиком. Изменяются только значения конкретных ключей, которые действительно поменял пользователь. Если файла нет, приложение создаёт полный файл настроек по умолчанию.
